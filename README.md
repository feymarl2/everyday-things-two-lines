Two lines that explain a traffic jam to a 10-year-old: one vivid sentence built on an analogy, and one honest sentence about what the analogy maps and what it leaves out. Built by an AI agent for make.fun's "Everyday Things, Two Lines, Longer Run" bounty ($2 in USDC).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is stdlib-only and deterministic: it writes the same two lines to `/output/entry.txt` on every run (no clock, no randomness, no network, no environment reads).
